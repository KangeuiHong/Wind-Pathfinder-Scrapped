# 바람결 · 지역별 바람과 관측소 비교

압축을 완전히 해제하고 **index.html**을 Chrome에서 여세요. 설치·빌드·서버·API 키가 필요 없습니다. 모든 화면은 같은 폴더 안의 상대 경로로 연결됩니다.

## 세 화면의 역할

- **Map View — index.html:** 지형과 전북의 43개 관측 위치를 보고 분석할 지점을 선택합니다
- **지역별 바람 비교 — NATIONAL_COMPARE.html:** 같은 시각의 전국 관측소별 풍향·풍속을 비교합니다. 자료 범위는 **2026-10-03 14:32–15:32 KST**입니다
- **Station View — VECTOR_COMPARE.html:** 선택한 전북 관측소의 **2024-10-06 00:00–23:59 KST** 하루를 비교하고 원본을 확인합니다
  - B: 1분 원본 / 5분 벡터평균 / 10분 벡터평균
  - A: 1분 원본 / 5분 벡터평균 / 5분 지속 상태변화
  - 상태 변화 기반 event sampling: 1분 원자료, 1 m/s 반지름 거리 기준, 검은 연결선·실제 시각 점 색
  - 한 분의 원본과 평균 상세, 24×60 Raw Matrix 한 곳

Map과 Station은 전북 관측소 선택을 공유합니다. 전국 비교는 날짜·범위가 다른 별도 자료를 사용하므로 Station의 하루와 이어진 관측으로 해석하지 않습니다. 전국은 **원래 v0.10 표현만** 사용하며, Station의 최종 시간 비교 방식은 아직 선택하지 않았습니다.

## 구성과 보존

별도 ‘이전 Matrix’와 별도 event sampling 화면을 Station View로 합쳤습니다. 지역별 바람 비교는 별도 화면으로 연결했습니다. 기존 Station A/B·벡터평균 페이지에서 반복하던 원본 그래프와 상세·행렬은 한 곳에 있습니다.

전북 원본 자료·지형·계산·그리기 규칙은 보존했습니다. 모든 43개 관측소에 대해 원본·평균·지속상태·event의 수치와 SVG 출력이 기존 구현과 같습니다. 전주 event는 계속 **43점·42개 검은 연결선**입니다.

## 전북 Station 자료와 해석

2024-10-06 KST 전북 풍향·풍속입니다. ASOS 10곳의 00:01–23:59 총 14,390개 원본 행을 사용합니다. 각 지점 00:00은 미확보이며 다음 날 00:00의 10행은 제외 목록에 보존합니다. 전주는 유효 1,439분(무풍 78), 부안은 유효 1,424분·풍속 결측 15분입니다. AWS 33곳은 위치만 확인했고 날씨값을 만들지 않습니다. 수치 유효는 QC 통과가 아닙니다.

A/B 원본과 평균의 연결 단절, event의 무풍 참여 및 결측 단절은 서로 다른 기존 규칙을 유지합니다. 선은 관측값의 시간순 비교 표식이며 실제 공기 이동 경로가 아닙니다.
